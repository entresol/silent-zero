A microkernel of the L4 family whose C implementation has a machine-checked proof of Functional correctness, first completed in 2009 for ARMv6 (seL4, Formal Verification of an OS Kernel). It provides a minimal set of mechanisms: threads, capabilities, virtual address spaces, IPC, notifications and interrupt delivery (Formally Verified Software in the Real World, §3.1). Drivers run in user mode, except the kernel’s timer (seL4, Formal Verification of an OS Kernel, §3.3, §3.4). Its proofs are in Isabelle/HOL in the seL4/l4v repository (seL4 Foundation: Verified Configurations).

The documentation page’s RISC-V section still called the MCS verification ongoing on 23 October 2026 (seL4 Foundation: Verified Configurations).

Size and cost

8,700 lines of C and 600 of assembler in 2009 (seL4, Formal Verification of an OS Kernel); about 10,000 lines of C later (Formally Verified Software in the Real World, §3; WCET analysis of seL4); just over 11,000 lines in the 64-bit RISC-V build analysed in 2026 (Resurrecting seL4’s WCET Analysis, §3). The first proof took about 20 person-years, 11 of them seL4-specific (seL4, Formal Verification of an OS Kernel, §5.2); all seL4-specific proofs to 2018 add up to 18 (Formally Verified Software in the Real World, sidebar).

Time

  • MCS makes processor time a capability with budget and period. See Mixed criticality.
  • WCET. A sound analysis existed for 32-bit Arm before MCS and was archived when Arm stopped publishing instruction latencies (WCET analysis of seL4, Trustworthy Systems: Guaranteeing timeliness of MCS on seL4). In the words of Sillitoe et al., seL4 thereby “lost any hard real-time guarantees” (§1). Since 2026 the analysis runs again on 64-bit RISC-V for the MCS configuration, still with placeholder values (Resurrecting seL4’s WCET Analysis). See WCET analysis.

In use

Under DARPA’s HACMS programme, seL4 carried the mission computer of Boeing’s Unmanned Little Bird, which stayed safe under a mid-flight cyberattack in 2017 (Formally Verified Software in the Real World).

Performance

Round-trip IPC on Intel Skylake: 986 cycles, against 2,717 for Fiasco.OC and 8,157 for Zircon, from Mi et al. 2019 as cited in MCS safety, an OS perspective.

Not yet in the wiki

CAmkES, the roadmap, the multicore proof. See also Time protection; systems built on seL4: Microkit, LionsOS.
