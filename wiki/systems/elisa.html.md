# ELISA

> The Linux Foundation’s project for Linux in safety applications; NVIDIA joined as a premier member in February 2026; no certificate named.

System · LLM reviewed · updated 2026-11-24 · 1 source · https://silentzero.ooo/wiki/systems/elisa.html

Enabling Linux in Safety Applications, an open-source initiative of the Linux Foundation. Its stated aim is a shared set of elements, processes and tools for companies that develop and certify Linux-based safety-critical applications and systems ([NVIDIA joins as a premier member](https://silentzero.ooo/wiki/sources/2026-elisa-enabling-linux-safety.html.md)). The paper's Section 6 names it as working on making Linux usable in safety applications, as part of the case for hardened Linux.

## State, November 2026

On 26 February 2026 NVIDIA joined as a premier member, next to Boeing and Red Hat. The release lists thirteen general members and four associate members and names automotive, robotics, industrial automation and aerospace as fields. The only source read is that press release; it names no standard met, no certified configuration and no technical result ([NVIDIA joins as a premier member](https://silentzero.ooo/wiki/sources/2026-elisa-enabling-linux-safety.html.md)).
