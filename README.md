# zOS – Zero OS

**A minimal, verified, real-time foundation for agents.** Working paper, 19 October 2026.

> Imagine it's 1991. We are about to release a few lines of code into a world that will be very different from today.

zOS is an operating system reduced to what cannot be removed: a bootloader, a formally verified microkernel, and the bare minimum needed to run AI agents safely and in real time. Nothing in it is new. Every component already exists as open-source work. What is new is the combination and the rule that binds it: whatever is not needed to run agents is not in the system, and whatever is in the system is proven, isolated, or explicitly named as trusted.
